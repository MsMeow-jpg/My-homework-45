# Homework 45 — Redux Cosmic Delivery App

## 📌 Project Description

This is a tutorial project created using **React + Vite**.

The project demonstrates how to manage global application state using **Redux Toolkit** and **React Redux**.

The application is styled as a fun **Futurama-style intergalactic delivery dashboard**.  
It has a bright cosmic interface with space delivery cards, neon colors, cartoon-like shadows, ship controls, strange planets, suspicious packages, and a chaotic sci-fi delivery company atmosphere.

The project implements:

- React project created with Vite
- Redux store created with `configureStore`
- Redux slice created with `createSlice`
- global state moved to Redux
- actions and reducers generated by Redux Toolkit
- app connected to Redux using `Provider`
- state reading with `useSelector`
- state updates with `useDispatch`
- delivery list stored in Redux state
- selected delivery stored in Redux state
- ship status stored in Redux state
- completed deliveries counter
- custom Futurama-inspired cosmic UI design
- interactive delivery cards
- control panel buttons for changing Redux state

## ⚙️ Installation and Launch
1. Clone the repository:
```bash
git clone https://github.com/MsMeow-jpg/My-homework-45
```
2. Go to the project folder:
```bash
cd My-homework-45/my-redux-app
```
3. Install dependencies:
```bash
npm install
```
4. Install Redux Toolkit and React Redux:
```bash
npm install @reduxjs/toolkit react-redux
```
5. Launch the project:
```bash
npm run dev
```
---
After this, the project will be available at:
```
http://localhost:5173
```

## 📦 Functionality
- The project uses Redux Toolkit for global state management
- Redux store is created with configureStore
- deliverySlice is created with createSlice
- reducers and actions are generated automatically by Redux Toolkit
- the application is wrapped with Redux Provider
- components read data from Redux using useSelector
- components update state using useDispatch
- SpaceHeader displays company, ship, and captain information
- ShipStatus displays current ship status and completed deliveries count
- ControlPanel dispatches actions to change ship status
- DeliveryList renders all active space deliveries
- DeliveryCard allows selecting a delivery
- selected delivery is highlighted with custom styling
- delivery status can be changed to Delivered
- completed delivery counter updates after successful delivery
- reset button returns the Redux state to its initial values
- UI updates automatically when Redux state changes

## 🚀 Redux State

The Redux state stores:
```bash
companyName          → Planet Express-ish Delivery
shipName             → Cosmic Rustbucket 3000
captain              → Captain Nibbly
shipStatus           → Current ship status message
selectedDeliveryId   → Currently selected delivery
completedCount       → Number of completed deliveries
deliveries           → List of intergalactic delivery orders
```
## 🧩 Main Components
```bash
SpaceHeader     → displays company, ship, and captain data
ShipStatus      → displays ship status and completed count
ControlPanel    → dispatches ship control actions
DeliveryList    → renders the list of deliveries
DeliveryCard    → displays one delivery and dispatches card actions
```
## ⚙️ Redux Actions

The project includes these Redux actions:
```bash
selectDelivery      → selects a delivery card
markAsDelivered     → changes delivery status to Delivered
launchShip          → updates ship status
cancelMission       → updates ship status
resetDeliveries     → resets the state to initial values
```
## 🧪 Testing the Project

To check if Redux works correctly:

1. Click Launch Ship

The ship status should change.

2. Click Cancel Mission

The ship status should change again.

3. Click Select on any delivery card

The selected card should receive a bright outline.

4. Click Mark Delivered
The delivery status should change to:
```bash
Delivered
```
The completed deliveries counter should increase.

5. Click Reset Deliveries

The app should return to the initial Redux state.

## 🔄 State Migration Explanation

This project is based on the idea of moving global application data from local state or Context into Redux.

- Global state includes:
- company name
- ship name
- captain name
- current ship status
- selected delivery
- completed deliveries counter
- list of delivery orders
Components use Redux instead of passing this data through props manually.

The app demonstrates how Redux can store shared data in one central place and update the UI through actions.
